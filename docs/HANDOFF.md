# Передача проекта в облако

## Цель и границы

Тестовый Texas Hold'em на условные фишки, оформление Смоленска, русский интерфейс. Владелец хочет продолжить разработку без привязки к домашнему компьютеру. Telegram Mini App пока не делать. Не добавлять денежные ставки/платежи.

## Две версии

Старые корневые файлы GitHub Pages сохранены. Рабочая версия сентября находится в `app/`; Node preview обслуживает только её. Главная картинка скопирована в `app/images/home.png`, поэтому рабочий сайт больше не зависит от старой GitHub Pages-картинки.

`app/table.html` содержит локальную тренировку и подключает `app/js/table-online.js` только при наличии `onlineRoom`. Онлайн-интерфейс не запускает ботов. `poker-api.js` вызывает проверяемые RPC; `lobby.js` обслуживает комнаты; `account.js` отвечает за авторизацию.

Пользовательские аватары, ник и стек старого локального кабинета не равны сетевому профилю/балансу. Сетевые стеки принадлежат конкретным столам. Гостевая сессия живёт в браузере; для другого устройства нужен постоянный аккаунт.

## Серверные исходники, в порядке применения

1. `server/schema.sql` — poker_v2_authoritative_engine.
2. `server/clock.sql` — poker_v2_server_clock (pg_cron раз в секунду).
3. `server/hardening.sql` — poker_v2_input_and_profile_hardening.
4. `server/reconnect.sql` — poker_v2_ready_reconnect.
5. `server/short-bet.sql` — poker_v2_incomplete_bet_reopening.

В Supabase существуют новые `public.poker_rooms`, `poker_players`, `poker_profiles` и приватные `games/hands/requests`, отдельно от старых комнат. Нельзя повторно применять bootstrap. `hardening.sql` зависит от старой `public.profiles`. SQL-проверки используют существующие auth.users в rollback-транзакциях. Новый проект базы требует отдельной подготовки, эти файлы не дают полного экспорта старого проекта.

## Состояние на момент передачи

22 сентября были проверены десять полных серверных раздач, побочные банки, сохранение фишек, закрытые карты, минимальный/короткий рейз, повторные и устаревшие запросы, отказ постороннему игроку. В двух отдельных браузерах прошли готовность, полная раздача, выплата, уборка карт, сохранение ползунка при опросах и перезагрузка. Мобильные размеры: 360×640, 390×844, 430×932; desktop: 1440×960. Это исторический результат, не новая проверка сервера.

5 октября добавлены переносимый Node preview, offline-тесты синтаксиса/ресурсов/HTTP-изоляции и инструкции для облака. Они не создают пользователей или комнаты и не проверяют действующий онлайн-сервер.

## Что осталось проверить/улучшить

- Реальную доставку email, привязку гостя, вход с двух физических устройств и Auth redirect allowlist под новый адрес.
- Привести локальный и сетевой личные кабинеты к понятной модели профиля, без смешения балансов.
- Отдельно провести аудит старых API/политик Supabase перед публичной эксплуатацией; перенос файлов не исправляет старый сервер.
- Подготовить полные воспроизводимые миграции для отдельного staging-проекта и автоматизированные тесты игрового движка без существующих пользователей.
- Проверить редкие комбинации олл-ин, неподдерживаемые браузеры, отключения и нагрузку; это пока тестовая версия.
- При публикации выбрать постоянный HTTPS-хостинг. Не считать preview URL постоянной ссылкой.
