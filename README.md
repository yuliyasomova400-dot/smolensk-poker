# Смоленский покер

Актуальная версия перенесена из локального проекта в `app/`. Старый сайт в корне сохранён без изменений.

## Запуск в облаке, Linux, macOS или Windows

Требуется Node.js 22 или новее. Сторонних npm-зависимостей нет.

```sh
npm test
npm start
```

Откройте порт **4173** через предпросмотр облачного окружения. Сервер слушает `0.0.0.0`, по `/` открывается выбор игры. Можно задать `PORT` и `HOST` переменными окружения. `npm start` не развёртывает базу и не изменяет её.

- `/play.html`: тренировка или игра с друзьями.
- `/table.html?mode=training`: боты без регистрации.
- `/login.html`, `/register.html`: онлайн-вход и постоянный аккаунт.
- `/rooms-online.html`: общий список новых онлайн-столов.
- `/mobile-preview.html`: мобильная рамка; она разделяет браузерную сессию с основным сайтом.

## Подключение Codex Cloud

1. Выберите эту ветку/версию репозитория при настройке окружения. Если интерфейс использует только `main`, сначала просмотрите и объедините pull request с облачной версией.
2. В Codex: **Work in → Cloud → Select environment → Create environment**; подключите этот репозиторий.
3. Попросите установить Node.js 22+, выполнить `npm test`, использовать `npm start` для предпросмотра с портом 4173. Установка npm-пакетов не нужна.
4. Для тренировки сеть не нужна. Для онлайн-режима разрешите HTTPS/WSS к `wymlgsraovjeqazzxosp.supabase.co`.
5. Проверьте отчёт настройки и нажмите **Publish**. Только после подтверждения публикации окружение доступно для новых облачных задач.

Официальная инструкция: https://learn.chatgpt.com/docs/environments/cloud-environments

Облачное окружение разработки **не является постоянным публичным хостингом** игры. Публикация сайта — отдельная задача. Локальные сессии/аккаунты браузера и история чата автоматически не переносятся.

## Сервер и безопасность

Серверная игра уже находится в Supabase. В репозитории сохранены SQL-исходники без выгрузки пользователей, сессий или базы. В браузере используется только publishable key. Для обычной тренировки и `npm test` никакие секреты не нужны.

**Не запускайте SQL-файлы повторно на действующей базе.** Они не являются самостоятельным инсталлятором: присутствуют зависимости от старой схемы и существующих пользователей. Перед изменением базы нужен отдельный тестовый проект и проверка миграций.

Доставка письма подтверждения и Supabase Auth Redirect URLs для нового preview/публичного адреса требуют отдельной проверки. Предыдущие проверки игры датированы 22 сентября 2026 года; они не подтверждают текущую доступность облачного сервера.

Контекст, устройство проекта и незавершённые задачи: [docs/HANDOFF.md](docs/HANDOFF.md).
